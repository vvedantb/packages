# Project skills

Design and motion skills for work on `@vvedantb/ui` and `@vvedantb/native-ui`.

Source: https://github.com/emilkowalski/skills (MIT, see `LICENSE-emilkowalski-skills`).
Copied unmodified from commit `0f2e23b32bb1265e84cff8d3e75785fec953fb1b` on 14 November 2026.

| Skill | Use it for | Package |
| --- | --- | --- |
| `animate` | Build a web animation from scratch | ui |
| `animate-expo` | Build Reanimated, Gesture Handler and haptics motion | native-ui |
| `review-animations` | Review a motion diff (run by hand: `/review-animations`) | ui |
| `improve-animations` | Audit all motion and write fix plans (read-only) | ui |
| `find-animation-opportunities` | Find places that should animate (read-only) | ui |
| `remove-animations` | Remove motion that should not exist | ui |
| `animation-performance` | Fix dropped frames | ui |
| `gestures` | Drag, swipe and sheet interactions | ui |
| `choreograph` | Staggers and multi-element sequences | ui |
| `emil-design-eng` | General component polish | ui |
| `apple-design` | Apple-style springs, materials and typography on the web | ui |
| `mobile-native` | Make web UI feel native on a phone | ui |
| `break-ui` | Stress-test a component with worst-case data | both |

To update, copy the skill folders again from upstream and change the commit above.
