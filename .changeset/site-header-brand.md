`SiteHeader` takes `brand` in place of `app`, so a site that is not a product app (Eva, Bee, Redline, flowtape) can use the same floating header with its own wordmark. `githubLabel` names its GitHub button. New optional `actions` slot before the CTA, shown at every width, for a small control such as a theme toggle.
