Add a `Stepper` primitive, exported from `@vvedantb/native-ui/primitives`. It is a controlled minus / value / plus row built from `IconButton`, with `min` (default 1), `max`, `step` (default 1), clamping, per-button accessibility labels and a `testID` that derives `-less` and `-more` for the two buttons.
