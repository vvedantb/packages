Add `ProductHeroOrbit`, the default concept visual for `ProductHero`: a glowing core with three orbit rings. Pass it as `visual` and set `accent` to tint it for a product. `children` puts a mark (for example the logo) in the core. Its motion is CSS only and stops under `prefers-reduced-motion: reduce`. Exported from `@vvedantb/ui` and `@vvedantb/ui/client`.
